# Numory

Memorise the numbers, tap 1 (the rest turn white), then tap them in order from memory. Lowest time wins; Easy, Medium and Hard each have a global Play Games leaderboard.

- Spec: `GOAL.md` · Why: `DECISIONS.md` · Prototype: `reference/prototype.html`
- `flutter analyze && flutter test`
- Sounds: `python3 tools/make_sfx.py`
